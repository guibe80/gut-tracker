# V3.3 Roadmap

Planned visualization work for Gut + Glucose Tracker V3.3:

1. Glucose graph view inspired by the iOS Health app.
2. Food timeline graph showing meal time and meal size using circles.
3. Carbohydrate and protein intake graphs.

All graph views should support selectable timeframes inspired by iOS Health, such as daily, weekly, monthly, and longer-range views where the data supports them.

The graph views should use the existing Supabase data and remain readable on desktop and mobile screens.
